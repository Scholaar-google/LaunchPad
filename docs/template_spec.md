# 立项文档模板字段规范

## 文档标准

输出文档格式为 **SOAP (标准立项文档)**，使用 `.docx` 格式生成。

## 文档结构

### 零、文档元信息

| 字段 | 说明 | 类型 | 必填 | 状态 |
|------|------|------|------|------|
| 文档编号 | PROJ-YYYYMMDD-HHmmSS | string | 是 | 已实现 |
| 生成时间 | ISO 8601 格式 | datetime | 是 | 已实现 |
| 文档版本 | v1.0 | string | 是 | 已实现 |

### 一、项目概述

| 字段 | 说明 | 类型 | 必填 | 状态 |
|------|------|------|------|------|
| 项目名称 | 简洁明确的项目名称 | string | 是 | 已实现 |
| 优先级 | high/medium/low | enum | 是 | 已实现 |
| 项目描述 | 200字以内的核心描述 | string | 是 | 已实现 |
| 业务目标 | 项目要达成的业务效果列表 | list[string] | 是 | 已实现 |
| 干系人 | 主要干系人及角色 | list[string] | 否 | 已实现 |

### 二、需求分析

| 字段 | 说明 | 类型 | 必填 | 状态 |
|------|------|------|------|------|
| 需求背景 | 为什么要做这个项目 | string | 是 | 已实现 |
| 需求描述 | 详细需求说明 | string | 是 | 已实现 |
| 包含范围 | scope_in | list[string] | 是 | 已实现 |
| 排除范围 | scope_out | list[string] | 否 | 已实现 |
| 约束条件 | 时间/预算/技术栈等约束 | list[string] | 否 | 部分（Intake 收集后在 renderer 中渲染） |

### 三、可行性评估

| 字段 | 说明 | 类型 | 必填 | 状态 |
|------|------|------|------|------|
| 总体结论 | 可行/基本可行/有风险需调整/不可行 | enum | 是 | 已实现 |
| 置信度 | 0.0~1.0 | float | 是 | 已实现 |
| 技术可行性 | 技术层面评估 | string | 是 | 已实现 |
| 业务可行性 | 业务层面评估 | string | 是 | 已实现 |
| 关键障碍 | 需要解决的关键问题 | list[string] | 否 | 已实现 |

### 四、资源需求

| 字段 | 说明 | 类型 | 必填 | 状态 |
|------|------|------|------|------|
| 资源评估结论 | 整体资源评估 | string | 是 | 已实现 |
| 置信度 | 0.0~1.0（数据不足自动调低） | float | 是 | 已实现 |
| 预计团队规模 | 需要的人数 | int | 是 | 已实现 |
| 预计工期 | 月数 | int | 是 | 已实现 |
| 预算范围 | 预估预算范围 | string | 否 | 已实现 |
| 资源依赖 | 依赖的外部团队或资源 | list[string] | 否 | 已实现 |

### 五、风险评估

| 字段 | 说明 | 类型 | 必填 | 状态 |
|------|------|------|------|------|
| 风险等级 | 低/中/高/极高 | enum | 是 | 已实现 |
| 置信度 | 0.0~1.0 | float | 是 | 已实现 |
| 风险评分 | 0.0~10.0 | float | 是 | 已实现 |
| 风险清单 | 每项含描述/概率/影响/应对措施 | list[RiskItem] | 是 | 已实现 |

**RiskItem 结构**：
- description: 风险描述
- probability: 发生概率（低/中/高）
- impact: 影响程度（低/中/高）
- mitigation: 应对措施

### 六、综合建议

| 字段 | 说明 | 类型 | 必填 | 状态 |
|------|------|------|------|------|
| 最终决定 | 建议立项/建议缓议/建议拒绝 | enum | 是 | 已实现 |
| 综合建议 | 详细建议文本 | string | 是 | 已实现 |
| 关键假设 | 决策所依赖的关键假设 | list[string] | 是 | 已实现 |
| 不确定项 | 需要进一步确认的事项 | list[string] | 是 | 已实现 |

### 七、免责声明（固定文本）

> 免责声明: 本报告由AI辅助生成，仅供参考，最终决策需由项目评审委员会确认。

状态：已实现（文档末尾自动附加，灰色斜体小字）

## 文档格式规范

当前实际渲染规范（简化自模板定义）：

- 正文：宋体(SimSun)，小四(12pt)
- 标题：使用 python-docx 默认 heading 样式
- 免责声明：9pt，灰色，斜体

> 注：原始规范要求的字体精细控制（黑体/三号/小三等）因跨平台兼容性进行了简化。

## 文档输出

- 文件格式：`.docx`
- 输出目录：`output/`（项目相对路径，已在 `.gitignore` 中排除）
- 文件命名：`{项目名称}_{YYYYMMDD_HHmmSS}.docx`
- 下载接口：`GET /api/projects/{id}/download`
