# 长链推理五步结构规范与示例

## 设计原则

综合 Agent (Synthesis) 的推理过程**必须**按以下五步结构展开，每步结果写入 `state.reasoning_chain`。

**禁止跳过任何一步**，即使前序步骤的结论已经非常明确。

Synthesis Agent 构建本地 `reasoning_chain` 列表，通过返回 dict 写入 state。禁止使用 `state.setdefault().append()` 原地修改 state。

## 五步推理结构

### 第1步：汇总层 (Summary Layer)

**目的**：提取三个并行 Agent 的核心结论与置信度，确保后续推理有清晰的信息基线。

**实现位置**：`src/agents/synthesis_agent.py` -> `_build_summary()`

**输出格式**：
```
可行性分析结论：[结论]（置信度：X%）
资源评估结论：[结论]（置信度：X%）
风险评估结论：[结论]（置信度：X%）
信息完整度评估：[完整/部分缺失/严重缺失]
```

**示例**：
```
可行性分析结论：技术可行（置信度：85%）
资源评估结论：当前资源可支撑，需增加 2 名后端开发（置信度：70%）
风险评估结论：中等风险，主要风险为第三方 API 依赖（置信度：75%）
信息完整度评估：部分缺失（缺少具体的技术栈偏好信息）
```

**特殊处理**：并行 Agent 超时或失败返回 None 时，标注"无数据（超时或失败）"。

### 第2步：冲突识别层 (Conflict Identification Layer)

**目的**：调用 `conflict_detector` 工具，找出三个维度结论之间的矛盾点。

**实现位置**：`src/agents/synthesis_agent.py` -> `detect_conflicts()` from `src/tools/conflict_detector.py`

**冲突检测规则**：
1. 可行性认为"可行"但资源认为"不足/缺乏" → 可行性 vs 资源矛盾
2. 可行性认为"可行"但风险评分 ≥ 7.0 → 可行性 vs 风险矛盾
3. 团队规模 > 20 人同时工期 ≤ 3 个月 → 资源计划内部矛盾
4. 风险含合规/监管问题但可行性未评估 → 合规覆盖缺失

**输出格式**：
```
发现 [N] 个矛盾点：
1. [矛盾主题]：[源A结论] vs [源B结论]
2. ...
无矛盾点。  （如无矛盾）
```

### 第3步：路径推演层 (Path Exploration Layer)

**目的**：针对每个矛盾推演 2~3 种解决路径，评估每条路径的优劣。

**实现位置**：`src/agents/synthesis_agent.py` -> `_explore_paths()`

**每条路径包含**：
- 路径描述
- 预期效果
- 实施难度
- 风险/收益

**输出格式**：
```
矛盾1：[主题]
  路径1：[描述] → 优点：[...]/缺点：[...]
  路径2：[描述] → 优点：[...]/缺点：[...]
  路径3：[描述] → 优点：[...]/缺点：[...]
推荐路径：[理由]
```

### 第4步：决策层 (Decision Layer)

**目的**：结合企业战略优先级（从 `CORPORATE_STRATEGY` 配置读取），选择全局最优路径，做出最终决策。

**实现位置**：`src/agents/synthesis_agent.py` -> `_get_corporate_strategy_context()`

**企业战略优先级配置**：

| 策略值 | 说明 | 优先级偏好 |
|--------|------|-----------|
| `growth` | 快速增长、抢占市场 | 高投入高产出，容忍适度风险 |
| `balanced` | 稳健发展、风险平衡 | 性价比最优，中等风险偏好（**默认值**） |
| `conservative` | 成本控制、安全第一 | 低风险低成本，保守策略 |

**配置方式**：在 `.env` 文件中设置 `CORPORATE_STRATEGY=balanced`，或通过环境变量传入。

**决策标准**：
1. 是否符合企业战略方向
2. 风险是否在可接受范围
3. 资源投入是否合理
4. 是否满足核心业务目标

**输出格式**：
```
[企业战略说明]
企业战略对齐度：[高/中/低]
核心业务目标满足度：[高/中/低]
综合风险评级：[低/中/高/极高]
最终决策：[立项/缓议/拒绝]
决策依据：[...]
```

### 第5步：输出层 (Output Layer)

**目的**：生成完整的最终建议，包括关键假设和不确定项清单。

**输出格式**：
```
最终建议：[立项/缓议/拒绝]
建议理由：[...]

关键假设：
1. [假设描述]（状态：有效/需验证）
2. ...

不确定项：
1. [不确定项描述]（影响程度：高/中/低）
2. ...

下一步行动：[...]
```

## 注意事项

1. 每步必须写入 `reasoning_chain`，即使内容为空也需记录"无数据"
2. 并行 Agent 返回 `None` 时，汇总层标注"超时或失败"
3. 前端 `ReasoningPanel` 通过 SSE 实时更新，后端 SSE 循环使用 `await asyncio.sleep(0.5)` 轮询
4. 五步推理是**强制要求**
5. Synthesis Agent 构建**本地 `reasoning_chain` 列表**，不在 state 上直接追加
6. 决策层必须通过 `_get_corporate_strategy_context()` 读取企业战略配置
